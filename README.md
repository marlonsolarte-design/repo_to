Implementando Comandos Básicos de Git

El objetivo de este taller es que aprendas e implementes los comandos básicos de Git en un entorno práctico. Al finalizar la actividad, deberás comprender cómo crear, gestionar y sincronizar repositorios locales y remotos, además de conocer los fundamentos de control de versiones.

Este taller lo guiará paso a paso para realizar operaciones básicas en Git mediante ejercicios sencillos. Usarás Git desde la línea de comandos y trabajarás con repositorios locales y remotos. Durante la actividad, practicarás comandos esenciales, como git init, git add, git commit, git push, entre otros.

Usamos VS code y Git CMD para realizar este taller.
